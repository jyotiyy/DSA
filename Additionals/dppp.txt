# 1D DP: FORWARD vs BACKWARD ITERATION

## Core Idea

In many 1D DP / Knapsack problems, the direction in which we iterate over the DP array determines whether the current item can be used multiple times or only once.

--------------------------------------------------
1. DP STATE
--------------------------------------------------

dp[s] = all combinations that can make sum s
        using the candidates processed so far.

Base case:

dp[0] = {{}}

Reason:
There is exactly one way to make sum 0:
choose nothing.

--------------------------------------------------
2. UNLIMITED USE OF AN ITEM
--------------------------------------------------

If an item/candidate can be used MULTIPLE TIMES:

    for (int s = x; s <= target; s++)

Use FORWARD iteration.

Why?

Suppose x = 2.

First:

    dp[2] ← dp[0] + 2
    dp[2] = [2]

Then while continuing forward:

    dp[4] ← dp[2] + 2
    dp[4] = [2,2]

Then:

    dp[6] ← dp[4] + 2
    dp[6] = [2,2,2]

Therefore:

    dp[0]
      ↓
    dp[2]
      ↓
    dp[4]
      ↓
    dp[6]

The newly created state can immediately be used again.

Therefore:

    FORWARD = ITEM CAN BE REUSED


--------------------------------------------------
3. USE AN ITEM ONLY ONCE
--------------------------------------------------

If an item/candidate can be used ONLY ONCE:

    for (int s = target; s >= x; s--)

Use BACKWARD iteration.

Suppose x = 2.

We process:

    target → ... → 2

When calculating a larger sum, dp[s-x] has NOT yet been
updated using the current x.

Example:

    s = 4

We check:

    dp[4-2] = dp[2]

But dp[2] has not yet been created during the current
iteration because we haven't reached s = 2.

Therefore the current 2 cannot be used again.

Eventually:

    s = 2

We create:

    dp[2] ← dp[0] + 2

But all larger states have already been processed.

Therefore this newly created dp[2] cannot be reused.

Hence:

    BACKWARD = ITEM CAN BE USED ONLY ONCE


--------------------------------------------------
4. WHY FORWARD CAUSES REUSE
--------------------------------------------------

Example:

    x = 2

Forward:

    s = 2
    dp[2] = [2]

    s = 4
    dp[4] uses dp[2]

But dp[2] was created using the CURRENT 2.

Therefore:

    [2] → [2,2]

Then:

    s = 6
    dp[6] uses dp[4]

Therefore:

    [2,2] → [2,2,2]

So forward iteration allows:

    2
    ↓
    2 + 2
    ↓
    2 + 2 + 2
    ↓
    ...

--------------------------------------------------
5. WHY BACKWARD PREVENTS REUSE
--------------------------------------------------

Example:

    x = 2

Backward:

    s = 7
    s = 6
    s = 5
    s = 4
    s = 3
    s = 2

When we calculate dp[4]:

    dp[4] uses dp[2]

But dp[2] has NOT been updated using the current 2 yet.

So [2,2] cannot be created.

Only later, when we reach s = 2:

    dp[2] = dp[0] + 2

But we have already passed s = 4.

Therefore the new dp[2] cannot be used again.

--------------------------------------------------
6. THE GOLDEN RULE
--------------------------------------------------

    Can use item multiple times?
                ↓
             FORWARD

    for (int s = x; s <= target; s++)


    Can use item only once?
                ↓
             BACKWARD

    for (int s = target; s >= x; s--)


--------------------------------------------------
7. COMBINATION SUM CONNECTION
--------------------------------------------------

Unlimited reuse:

    for (int x : candidates) {
        for (int s = x; s <= target; s++) {
            ...
        }
    }

Forward iteration allows:

    [2]
    [2,2]
    [2,2,2]
    ...

Therefore candidates can be reused.


If each candidate can be used only once:

    for (int x : candidates) {
        for (int s = target; s >= x; s--) {
            ...
        }
    }

Backward iteration prevents the current candidate from
being used again.

--------------------------------------------------
8. EASY WAY TO REMEMBER
--------------------------------------------------

FORWARD:

    Newly created state
           ↓
    can be used immediately
           ↓
    REUSE ALLOWED


BACKWARD:

    Newly created state
           ↓
    all relevant states already processed
           ↓
    REUSE NOT ALLOWED


--------------------------------------------------
9. INTERVIEW ONE-LINER
--------------------------------------------------

"Forward iteration allows the current item to contribute
to states that are processed later, so the item can be
used multiple times.

Backward iteration ensures that the current item cannot
be reused within the same iteration, so it is used at most
once."


--------------------------------------------------
10. MOST IMPORTANT PATTERN
--------------------------------------------------

UNBOUNDED / UNLIMITED KNAPSACK:

    for (s = x; s <= target; s++)
        // FORWARD


0/1 KNAPSACK:

    for (s = target; s >= x; s--)
        // BACKWARD


MEMORIZE:

    FORWARD  → REUSE
    BACKWARD → USE ONCE
